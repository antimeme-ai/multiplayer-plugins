# `/leave` — Leave the Active Party

1. Call `party_leave` on the `multiplayer` MCP server (`mp-outpost mcp`) with `{}` (or `{ party_id }` if the operator specified a numeric `party_id`).
2. Confirm that the local outpost detached cleanly and report the `party_id` left.
